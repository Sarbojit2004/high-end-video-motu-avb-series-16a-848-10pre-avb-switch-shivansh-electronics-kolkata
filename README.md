# MOTU AVB Series — Three-Part Reel Series

Three sequential 178-second vertical reels (1080×1920, 30 fps) covering the MOTU
AVB ecosystem — **10pre**, **16A**, **848** and the **AVB Switch** — for
**Shivansh Electronics**, Authorized Distributor of MOTU (Mark of the Unicorn,
USA) Interfaces for East and North East India.

| Part | Chapter | Product | Output |
|---|---|---|---|
| 1 | THE SOURCE | MOTU 10pre | `out/motu-avb-reel-part1-10pre.mp4` |
| 2 | THE MATRIX | MOTU 16A | `out/motu-avb-reel-part2-16a.mp4` |
| 3 | THE COMMAND CENTER & THE NETWORK | MOTU 848 + AVB Switch | `out/motu-avb-reel-part3-848-avbswitch.mp4` |

All three are chapters of one continuous argument — **one identical engine,
three specialised front-ends, one scalable AVB network** — not three standalone ads.

---

## Quick start

```bash
npm install
npm run setup     # copy assets + fonts, synthesize SFX, build music beds & SFX timelines
npm run render:part1
npm run render:part2
npm run render:part3
npm run render:thumbs
```

`npm run setup` is required before the first render — it populates `public/`,
which is gitignored for images/audio.

### Rendering notes

This container ships Chromium and blocks Remotion's browser-download host, so
`remotion.config.ts` points the renderer at the local binary. Override with:

```bash
export REMOTION_BROWSER_EXECUTABLE=/path/to/chrome
```

**without losing sync**:

| File | Contents |
|---|---|
| `public/audio/music-bed-part{N}.mp3` | The selected bed with its selected stems and per-chapter automation. Music only. |
| `public/audio/sfx-timeline-part{N}.mp3` | **Transition SFX only, music fully silent**, each cue at the exact frame it fires — one continuous file spanning the full 178.000 s / 5,340-frame timeline. |

## Audio design

**Music bed — selected on analysis, not on filename.** `scripts/analyze-music.mjs`
measured tempo, onset density, band balance and dynamics on all four supplied
tracks. Results:

| Track | bpm | onsets/s | low% | mid% | verdict |
|---|---|---|---|---|---|
| Black & Blue | 184.6 | 1.38 | 81.6 | 15.3 | sub-bass dominant |
| DIABLO | 107.7 | 1.13 | 85.7 | 12.2 | sub-bass dominant |
| ETERNITY | 184.6 | **0.03** | 89.8 | 9.2 | sustained drone — ruled out |
| GIFTED | 184.6 | 0.70 | 92.0 | 6.5 | sub-bass dominant |
| **Mindscape** | 71.8 | **4.38** | 37.6 | **59.8** | **selected** |

`ES_Mindscape - Lennon Hutton` is the only track with genuine midrange content
(59.8 % vs ~10 % elsewhere), so it will not mask narration; the only one longer
than 178 s (185.8 s → **no loop seam in any part**); and the most headroom at
−13.8 LUFS. ETERNITY was excluded outright as the "formless drone" the brief
warns against.

**Deployment: Path A — Ecosystem Unification.** One core track across all three
parts, with per-chapter stem layering (BASS / INSTRUMENTS / MELODY). The series'
thesis is *one engine, three front-ends*; a single musical engine whose layers
change per chapter argues exactly that. Path B would sonically claim the opposite.

**Transition SFX — synthesized in-process** by `scripts/make-sfx.mjs` (pure Node
DSP, no external audio service). Every element is band-limited above ~150 Hz so
it sits in the gaps of the bed rather than under it — no cinematic low-frequency
whooshes anywhere.

| Cue | Role |
|---|---|
| `encoder-click` | aluminium encoder detent — front-panel control beats |
| `rj45-snap` | Ethernet plug seating — networking/connection beats |
| `avb-ping` | successful AVB handshake — topology animation moments |
| `data-stream` | high-frequency shimmer — ambient top/bottom-zone fill |
| `talkback-click` | 848 talkback button — Part 3 control-room beat |

### Typography (locked, identical across all three parts)

Structurally ported from the established project type system (Fraunces display +
Archivo technical grotesque); **colour values re-derived from scratch** for this
project's light background — the source project was dark-on-dark and none of its
text colours or scrim technique carried over.

|---|---|---|---|---|---|---|
| 1 | Headline | Fraunces | 700 | 118 px | −0.025em | mask-up + spring settle |
| 2 | Subheadline | Fraunces | 500 | 52 px | −0.010em | fade + 18 px rise |
| 3 | Spec numerals | Archivo | 800 | 92 px | −0.010em | odometer count-up |

### Render-quality gate

`remotion.config.ts` sets an explicit **9 Mbps** target rather than CRF. CRF is
quality-targeted, and this content (flat light grounds, vector motion graphics,
1U hardware on plain wells) is genuinely low-complexity — a CRF-18 pass settles
around 2.1 Mbps / 45 MB, which is not a soft encode but does miss the 8–12 Mbps
delivery spec. 9 Mbps × 178.05 s ≈ 200 MB video + ~7 MB audio.

## Content verification

Filenames in this repo do **not** reliably indicate content, so every image was
visually inspected via contact sheets (`scripts/contact-sheets.mjs`) before use.

**Excluded — 3 files, 1 distinct image:**

| File | Reason |
|---|---|
| `MOTU 10pre (23).jpg` | Moog modular synthesizer — third-party hardware, not any MOTU product |
| `MOTU 16A (3).jpg` | byte-identical to the above |
| `MOTU 848 (6).jpg` | byte-identical to the above |

Coverage: **136 / 136** valid images placed across the three parts.

Two findings worth recording, both checked rather than assumed:
- `MOTU AVB SWITCH (2).png` is not blank — it is the **IEEE 802.1 AVB** badge at
  120×55 px, so it is used at badge scale only.
- The 10pre "newly added" shots show an A/B/C + TALK control cluster. That is
  genuine, correctly-labelled 10pre photography (the chassis is branded "10pre"),
  so talkback is never claimed as an 848-exclusive feature anywhere in the series.
